SysID Usage Instructions

Downloading a Log File

  1. Connect to the Robot
  2. Open the dashboard at robot.local
  3. Navigate to the Logs Page and select the log that has the sysID test that was run

Opening the Log File and Retrieving Data

  1. Open the System Identification Tool
  2. Select the log file from your downloads and open it
  3. In the search bar of the Log Loader panel, type SysID and something and open the dropdowns to find SysIDState
  4. Drag the SysIDState into the Data Selector
  5. For an elevator select elevator, for pivot mechanisms select arms, and for anything else (rollers & swerve) select simple.
  6. Then ensure the searchbar of the Log Loader panel is clear and then drag the position, velocity, and voltage readings into the data selector. If there are multiple motors for the same subsystem make sure to use the one that does not say follower. In the case of swerve make sure that you repeat this process for each of the 4 swerve modules
  7. Once you press load in the data selector panel, the analyzer panel will pop up with readings for kP, kI, kD, kG, kV, kS, and kA. If you do not see one of those values in the code have them equal 0.
  8. Then ensure that the robot is in tuning mode (can be changed in config) and go back to advantage scope, and find the text boxes with places for each of the values in that subsystem and replace them. Then run a test by running different velocity/voltage to the subsystem several times. If the speed visibly changes then you are done. If not carefully change one value at a time in small increments/decrements until the expected results are obtained
  9. Lastly ensure that the values are put in the constants file in their respective places
